# - CodeChop -

## NC Toolpath Visualization

Written in VB.NET.
___
Uses Tao OpenGL, which is very old but works on most video hardware.

Use at your own risk. What you use this for, I don’t care, but I have zero accountability if you “fuck the dog.” That’s on you.

Right-clicking the > arrow will run the code so you can see it.
The icons at the top are easy to understand.
When loading a huge file, CodeChop may look unresponsive. It isn’t; let it digest the G-code so it can plot correctly.
